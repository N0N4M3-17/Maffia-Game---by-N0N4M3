# Local UI Assets

- `assets/card-back.svg` and `assets/joker.svg`: original artwork created for this project; distributed under the repository's terms.
- `vendor/lucide.js`: Lucide 0.468.0, ISC licence. The upstream licence is included alongside the bundle. https://lucide.dev
- Typography uses locally installed Georgia and system sans-serif fallbacks; no remote font requests.

All runtime artwork and icons are served by the Java host. No CDN is required.
